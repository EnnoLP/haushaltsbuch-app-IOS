# Components

Dieser Ordner ist für wiederverwendbare UI-Komponenten vorgesehen.

Aktuell sind alle Komponenten direkt in den jeweiligen Screen-Dateien enthalten:

| Komponente | Datei |
|-----------|-------|
| `TxRow` | `screens/DashboardScreen.js` |
| `TxCard` | `screens/TransactionsScreen.js` |
| `Label` | `screens/AddScreen.js` |

Zukünftige Komponenten können hier ausgelagert werden.
